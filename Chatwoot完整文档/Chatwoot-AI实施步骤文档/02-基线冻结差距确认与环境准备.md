# 基线冻结、差距确认与环境准备

> 批次：BAS，共 12 项。完成本分册后才允许进入公共合同和对象实施。共同基线：[全系统基础层规范](../Chatwoot全系统基础层规范/README.md)、[目标系统架构](../Chatwoot模块化架构设计文档/10-可扩展简单实用可跟踪可量化可分可合目标架构.md)和[实际基线参数与量化目标冻结表](29-实际基线参数与量化目标冻结表.md)。

## 1. 目标

把“要实现什么、按什么基础层实现、如何组合部署、如何量化完成”冻结为可核对基线，避免实施期间因版本、配置、Feature、第三方能力、模块边界、部署形态或数据样本不明确而反复变化。

## 3. 差距分类方法

| 分类 | 判断条件 | 实施动作 |
|---|---|---|
| 保留 | webchat 已有完整业务闭环且目标不冲突 | 纳入统一对象和验收，不重复建立 |
| 调整 | 已有相邻能力但对象、状态、权限或接口不同 | 保留业务价值，统一目标合同 |
| 新增 | 未形成目标业务闭环 | 按功能任务完整实施 |
| 替换 | 现有行为与目标互斥且无法兼容 | 设计迁移和回退后替换 |
| 排除 | 目标形态明确不适用 | 记录原因、批准、期限和重开条件 |

## 4. 基线包最低字段

### 4.1 版本与部署

- foundation_version、产品版本、构建标识、合同版本、部署日期；
- 开源、企业或 Cloud 形态；
- 26 个逻辑模块的 module_id、职责、权威对象和启用状态；
- U1 至 U5 的模块映射、节点数量、区域、容量和故障边界；
- 当前是组合、部分拆分还是完全独立部署；
- 数据库、缓存、异步任务和对象存储的可用状态；
- 主域名、Widget 域名、回调域名和帮助中心域名；
- API 版本前缀和旧入口兼容范围。

### 4.2 Account

- account_id、名称、语言、时区、状态；
- Feature、套餐、额度、安装配置继承结果；
- Administrator、Agent、自定义角色；
- 至少一个网站 Inbox 和一个第三方 Inbox；
- Team、Inbox 成员、容量和分配策略。

### 4.3 外部依赖

- Provider 名称和 API 版本；
- 授权方式、Scope、Token 到期和轮换方式；
- 回调地址、签名方式、订阅事件和验证状态；
- 测试发送目标、真实回执和限流条件；
- 服务不可用时的替代验证及其不能覆盖的范围。

## 5. 架构基线冻结

### 5.1 26 个逻辑模块

必须逐项登记：IAM、TEN、ENT、SYS、CHN、CUS、MED、CON、MSG、RTE、TKT、QLT、AUT、OPS、ORC、NTF、KB、AIC、EXT、MIG、BIL、API、RTM、RPT、SRH、AUD。

每个模块至少冻结：职责、禁止边界、权威对象、Command、Query、Event、Capability、同步依赖、事件依赖、Change Registry、数据分级、指标和停用行为。

### 5.2 五个默认运行单元

| 运行单元 | 默认模块 | 基线要求 |
|---|---|---|
| U1 Edge | API、RTM | 外部入口、实时连接、限流和补读 |
| U2 Control | IAM、TEN、ENT、SYS | 身份、租户、权限、Feature 和配置 |
| U3 Core | CHN、CUS、MED、CON、MSG、RTE、TKT、QLT | 核心客服和数据所有权 |
| U4 Capability | AUT、OPS、ORC、NTF、KB、AIC、EXT、MIG、BIL | 自动化、宏、AI、插件和长流程 |
| U5 Insight | AUD、RPT、SRH | 审计、报表和搜索 |

组合部署不能取消模块合同、数据边界、Local Journal、指标或故障归属。目标环境已经拆分的模块，应记录实际运行单元并保留与默认组合的对应关系。

### 5.3 六项目标量化基线

| 目标 | 固定门槛 | 必须填写的环境数值 |
|---|---|---|
| 可扩展 | 未登记 Capability/Adapter/插件入口为 0；扩展合同覆盖率 100% | 新扩展接入周期、合同验证时长、版本兼容窗口 |
| 简单实用 | 默认运行单元为 5；单模块动作错误进入 ORC 的数量为 0 | 部署步骤数、启动时间、基础资源和运维入口数量 |
| 可跟踪 | 成功数据变化有 change_id 为 100%；跨模块 correlation 覆盖率 100% | 日志查询时延、投递延迟、保留周期 |
| 可量化 | 关键 Command、流程、外部调用和业务结果指标覆盖率 100% | 可用性、P95/P99 延迟、错误率、积压水位、成本上限 |
| 可分 | 26/26 模块有接入声明；跨模块内部存储访问为 0；依赖环为 0 | 选定模块拆分时间、RTO、RPO、数据迁移窗口 |
| 可合 | 组合与拆分部署适用案例通过率 100%；结果差异为 0 | 合并部署资源、切换窗口和观察期 |

所有“必须填写”的数值必须在 BAS-08/BAS-11 证据中给出具体值、单位、测量窗口和数据来源。未另行冻结时直接使用 29 分册 P1 标准档，不再允许留下空白；成本金额等无法通用预设的项目必须在目标环境填写。使用“以后确定”“尽量”或“合理范围”不能关闭 BAS。
