## 1. 目标

完成客服系统核心业务：会话创建、查询、状态、优先级、分配、参与者、消息、附件、已读、发送状态、失败重试、私有备注和全部可观察副作用。

## 3. 消息任务

| 编号 | 功能 | 逐步实施 | API 与字段 | 完成判定 |
|---|---|---|---|---|
| CONV-13 | 入站文本 | 接收客户文本；识别 ContactInbox；去重；更新会话 | content、message_type=incoming、external_id | 一条外部消息只生成一条内部消息 |
| CONV-14 | 出站文本 | 校验会话与渠道状态；创建待发送消息；送往 Provider；更新最终状态 | content、message_type=outgoing、status | 接受、发送、送达、已读和失败可区分 |
| CONV-15 | 私有备注 | 创建仅账号成员可见消息，不发送客户和 Provider | private=true | Widget、Public 和客户事件不泄露 |
| CONV-16 | 活动消息 | 为状态、分配、标签等变化形成活动记录 | message_type=activity | 文案和结构不冒充客户消息 |
| CONV-17 | 内容类型 | 支持文本、输入邮箱、选择、表单、卡片、位置等适用类型 | content_type、content_attributes | 不支持类型返回明确错误 |
| CONV-18 | 附件 | 上传、关联、读取、下载和安全状态；支持图片、音频、视频、文件 | attachments、file_type、file_size | 越权下载被拒绝，失败不产生孤立引用 |
| CONV-19 | 引用与回复 | 保存被引用消息、渠道可用性和降级结果 | in_reply_to、external identifiers | 不支持原生引用时保持内容可理解 |
| CONV-20 | 消息更新 | 处理内容修正、Provider 状态、转写和情绪等允许变化 | status、processed_content、sentiment | 只读字段不能被普通入口伪造 |
| CONV-21 | 删除消息 | 按身份、时间、渠道和类型执行删除或隐藏 | message_id | 本地、Provider、事件和历史结果明确 |
| CONV-22 | 失败重试 | 查询原状态；判定可重试；复用幂等键；更新重试次数 | retry_count、error_code | 不产生重复客户消息 |
| CONV-23 | 草稿 | 保存、读取、更新、清除每个成员的服务端草稿 | draft message、has_draft | 草稿不发送、不触发客户事件 |
| CONV-24 | 消息副作用 | 统一会话活动时间、未读、通知、实时、Webhook、Bot、报表和审计 | 40 分册副作用模型 | 各入口触发相同副作用集合 |

## 4. 单条出站消息流程

1. 校验发送者、Account、Inbox、会话和渠道状态；
2. 校验内容类型、附件和 Provider 能力；
3. 使用请求幂等键或 echo_id 检查重复；
4. 创建待发送消息并返回可查询标识；
5. 更新会话活动时间和必要通知；
6. 提交 Provider 发送；
7. 保存外部消息 ID；
8. 接收发送、送达、已读或失败回调；
9. 按允许状态顺序更新消息；
10. 推送实时事件、Webhook 和报表变化；
11. 超时后先查询原结果，再决定补偿；
12. 最终进入可解释终态。

## 5. 必测场景

- 两个请求同时创建同一客户在同一 Inbox 的会话；
- 两名成员同时领取、转接或解决会话；
- open、resolved、pending、snoozed 状态竞争；
- 同一 echo_id、external_id 和 Provider 回调重复；
- 出站接受后网络超时但 Provider 实际已发送；
- 状态回调乱序、重复和缺失；
- 删除与重试同时发生；
- 私有备注在 Widget、Public、Webhook 和实时事件中的可见性；
- 大附件、不支持格式、安全扫描失败和下载越权；
- 消息创建后通知、未读、报表和审计是否同步。
