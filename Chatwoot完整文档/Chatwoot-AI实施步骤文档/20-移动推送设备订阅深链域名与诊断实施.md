# 移动推送、设备订阅、深链、域名与诊断实施

> 批次：MOB，共 14 项。基线来源：[28](../Chatwoot产品与API文档/28-移动端推送诊断与客户端入口API.md)、[13](../Chatwoot产品与API文档/13-身份资料安全与登录会话API.md)、[47](../Chatwoot产品与API文档/47-webchat开放平台安全审计与企业能力补齐规范.md)和[30-第三方真实环境与最终接口冻结表](30-第三方真实环境与最终接口冻结表.md)。

## 1. 目标

统一 Browser Push、Android FCM、iOS 推送的设备订阅、偏好、投递、失效清理、深链、域名关联、移动 SAML 回跳、Widget WebView 和安装级诊断。

## 2. 任务清单

| 编号 | 功能 | 逐步实施 | API 与字段 | 完成判定 |
|---|---|---|---|---|
| MOB-01 | 订阅创建 | 识别 browser、fcm、ios；校验当前 User、设备和 Token；建立订阅 | `/notification_subscriptions`；subscription_type、push_token | 同设备重复登记不产生无限记录 |
| MOB-02 | Browser Push | 保存 endpoint、keys、浏览器和权限状态 | endpoint、p256dh、auth | 拒绝权限和失效 endpoint 可识别 |
| MOB-03 | Android FCM | 保存 Token、设备、应用版本和最近活动 | push_token、device_id、app_version | Token 轮换后旧 Token 停用 |
| MOB-04 | iOS 推送 | 保存 APNs 或目标推送标识、环境和应用信息 | token、environment、bundle | 测试与正式环境不混用 |
| MOB-05 | 订阅删除 | 用户退出、设备撤销或手动删除时关闭订阅 | subscription_id | 删除幂等且不影响其他设备 |
| MOB-06 | 通知选择 | 结合通知类型、Account 偏好、静音、设备状态和通道配置 | notification_type、preferences | 未启用事件不推送 |
| MOB-07 | Payload | 生成标题、正文、Account、资源、深链和最小必要数据 | title、body、account_id、resource_id、deep_link | 不包含私有备注和敏感字段 |
| MOB-08 | 投递状态 | 记录受理、成功、失败、失效和重试 | delivery_status、error_code | 站内通知与推送结果分开 |
| MOB-09 | 失效清理 | Provider 返回无效 Token 时停用并记录原因 | invalid_at、failure_count | 不继续向失效 Token 重复发送 |
| MOB-10 | 深链 | 将通知打开到正确 Account、会话、联系人或其他页面 | deep_link、resource_type | 无权、已删除和跨账号资源安全降级 |
| MOB-11 | Android/iOS 域名关联 | 提供关联文件并验证目标应用、域名和缓存更新 | package、bundle、team id | 系统可验证并打开目标应用 |
| MOB-12 | 移动 SAML 回跳 | 在浏览器完成 SAML 后安全返回移动应用并交付一次性结果 | RelayState、callback | 防重放和错误应用接收 |
| MOB-13 | Widget WebView | 保持访客身份、附件、返回键、外链和安全边界 | widget token、origin | 与普通浏览器聊天结果一致 |
| MOB-14 | 推送诊断 | 安装管理身份选择订阅并测试，返回配置、发送和 Provider 结果 | diagnostic status、error | 可按 28 分册顺序定位故障 |

## 3. 推送处理流程

1. 业务事件生成站内 Notification；
2. 读取用户在当前 Account 的事件和通道偏好；
3. 检查会话静音、资源可见性和设备状态；
4. 为每个有效订阅生成最小 Payload；
5. 提交对应推送 Provider；
6. 记录每台设备的投递结果；
7. 对可重试错误延迟重试；
8. 对无效 Token 停用订阅；
9. 用户点击时重新验证登录、Account 和资源权限；
10. 打开目标页面或安全回退到列表。

## 4. 必测场景

- 同一账号三台设备和同一设备 Token 轮换；
- 用户退出、撤销设备、移出 Account 后继续收到通知；
- 通知偏好关闭、会话静音和资源无权；
- Provider 暂时失败、永久失效和限流；
- 深链目标已删除、会话不再可见或属于其他 Account；
- Android 与 iOS 域名文件缓存更新；
- SAML 回跳被重复使用或发给错误应用；
- Widget WebView 第三方 Cookie、附件和外链行为；
- 安装配置缺失时诊断能指出具体阶段。
