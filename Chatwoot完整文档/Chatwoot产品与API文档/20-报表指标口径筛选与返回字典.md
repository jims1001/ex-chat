# 报表指标口径、筛选与返回字典

> 导航：[全体功能与 API 总表](00-全体功能与API总表.md)｜[报表、SLA、帮助中心与搜索 API](08-报表SLA帮助中心与搜索API.md)

## 1. 功能范围

报表 API 提供时间趋势、当前与上一周期汇总、成员/团队/Inbox/标签汇总、实时会话指标、机器人指标、首响分布、Inbox×标签矩阵和 CSV 导出。报表权限通常属于 Administrator；企业版拥有 report_manage 的自定义角色也可访问报表与 CSAT。

## 2. 趋势与汇总 API

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | /api/v2/accounts/{account_id}/reports | 指定指标的时间趋势 |
| GET | /api/v2/accounts/{account_id}/reports/summary | 当前周期与上一周期汇总 |
| GET | /api/v2/accounts/{account_id}/reports/bot_summary | 机器人解决和转人工汇总 |
| GET | /api/v2/accounts/{account_id}/reports/drilldown | 指标明细，仅 Administrator |

## 3. 公共筛选字段

| 字段 | 类型 | 说明 |
|---|---|---|
| since | Unix 秒 | 开始时间，包含 |
| until | Unix 秒 | 结束时间，通常不包含 |
| metric | enum | 趋势或明细指标 |
| type | enum | account、agent、inbox、team、label |
| id | integer | type 不是 account 时的目标 ID |
| group_by | enum | hour、day、week、month、year；无效值按 day |
| timezone_offset | number | 时间分桶使用的时区偏移 |
| business_hours | boolean | 平均时长是否只统计营业时间 |
| page、per_page | integer | Drilldown 分页 |
| bucket_timestamp | Unix 秒 | Drilldown 指定的趋势时间桶 |

since 与 until 形成半开时间范围。切换 timezone_offset 会改变分桶边界，但不应改变同一绝对时间范围内的原始事件。

## 4. 核心指标口径

| metric | 聚合 | 单位 | 计算口径 |
|---|---|---|---|
| conversations_count | count | 条 | 时间范围内创建的会话数 |
| incoming_messages_count | count | 条 | 时间范围内的 incoming 消息数 |
| outgoing_messages_count | count | 条 | 时间范围内的 outgoing 消息数 |
| avg_first_response_time | average | 秒 | 从最近一次非人工活动起点到首次人工回复的平均时长 |
| avg_resolution_time | average | 秒 | 从会话创建到进入 resolved 的平均时长 |
| reply_time | average | 秒 | 从客户等待起点到人工回复的平均时长 |
| resolutions_count | count | 次 | 时间范围内 conversation_resolved 事件数 |
| bot_resolutions_count | count | 个会话 | Bot 解决且同范围没有转人工的会话数 |
| bot_handoffs_count | count | 个会话 | 发生 Bot 转人工的去重会话数 |

resolutions_count 统计解决事件，不等同于唯一已解决会话数；一个会话被重新打开后再次解决，可能产生新的解决事件。reply_time 在分组汇总响应中使用 avg_reply_time 字段名。

## 5. 营业时间口径

business_hours 为 true 时，avg_first_response_time、avg_resolution_time 和 reply_time 使用 Inbox 营业时间内的有效秒数。计数指标不因该开关变化。

| 场景 | business_hours=false | business_hours=true |
|---|---|---|
| 非营业时间收到消息，次日回复 | 计算完整经过时间 | 只计算营业时间段 |
| 全天开放 Inbox | 与自然时间接近 | 与自然时间接近 |
| 未配置营业时间 | 按产品当前营业时间规则处理 | 验收时必须核对实际结果 |

跨 Inbox 汇总时，每条事件按所属 Inbox 的工作时间计算，不能用单一 Account 时区重新估算。

## 6. 趋势响应

计数趋势元素包含 value 和 timestamp。平均时长趋势元素还包含 count，表示该时间桶中参与平均值的事件数。

| 字段 | 类型 | 说明 |
|---|---|---|
| value | number | 计数或平均秒数 |
| timestamp | Unix 秒 | 时间桶起点 |
| count | integer | 平均指标的样本数，计数指标通常不提供 |

没有事件的时间桶可能返回 value 为 0，也可能在部分聚合结果中省略。使用方应补全展示时间轴，但不能把“无样本”解释为“平均时长为 0 秒”。

## 7. Summary 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| conversations_count | integer | 创建会话数 |
| incoming_messages_count | integer | 客户消息数 |
| outgoing_messages_count | integer | 发出消息数 |
| avg_first_response_time | number 或 null | 首次响应平均秒数 |
| avg_resolution_time | number 或 null | 解决平均秒数 |
| resolutions_count | integer | 解决事件数 |
| reply_time | number 或 null | 回复平均秒数 |
| previous | object | 与当前周期等长的上一周期相同字段 |

上一周期从 since 向前平移当前范围长度。current 和 previous 应使用相同 type、id、timezone_offset 和 business_hours。

## 8. 分组汇总 API

| 方法 | 路径 | 分组对象 |
|---|---|---|
| GET | /api/v2/accounts/{account_id}/summary_reports/agent | 成员 |
| GET | /api/v2/accounts/{account_id}/summary_reports/team | 团队 |
| GET | /api/v2/accounts/{account_id}/summary_reports/inbox | Inbox |
| GET | /api/v2/accounts/{account_id}/summary_reports/label | 标签 |
| GET | /api/v2/accounts/{account_id}/summary_reports/channel | 渠道类型 |

agent、team、inbox 和 label 常用返回字段：id、name、conversations_count、resolved_conversations_count、avg_resolution_time、avg_first_response_time、avg_reply_time。不同对象还会返回头像、邮箱、渠道或其他展示字段。

channel 返回每种 channel_type 的 open、resolved、pending、snoozed 和 total。该接口单次时间范围不能超过六个月。

## 9. 实时会话指标

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | /api/v2/accounts/{account_id}/live_reports/conversation_metrics | Account 或指定 Team 的实时数量 |
| GET | /api/v2/accounts/{account_id}/live_reports/grouped_conversation_metrics | 按 team_id 或 assignee_id 分组 |

conversation_metrics 返回：

| 字段 | 含义 |
|---|---|
| open | 当前 open 会话数 |
| unattended | 当前 open 且尚未被有效处理的会话数 |
| unassigned | 当前 open 且没有负责人的会话数 |
| pending | 当前 pending 会话数 |

grouped_conversation_metrics 只对 open 会话统计 open、unattended 和 unassigned，并附带 team_id 或 assignee_id。它是当前状态快照，不使用 since 和 until。

## 10. 机器人指标

| 方法 | 路径 | 返回字段 |
|---|---|---|
| GET | /api/v2/accounts/{account_id}/reports/bot_metrics | conversation_count、message_count、resolution_rate、handoff_rate |
| GET | /api/v2/accounts/{account_id}/reports/bot_summary | bot_resolutions_count、bot_handoffs_count、previous |

| 字段 | 口径 |
|---|---|
| conversation_count | 绑定有效 Bot 的 Inbox 在范围内创建的会话数 |
| message_count | 上述会话在范围内产生的 outgoing 消息数 |
| resolution_rate | Bot 解决且未转人工的会话数 ÷ Bot 会话数 × 100 |
| handoff_rate | 发生转人工的去重会话数 ÷ Bot 会话数 × 100 |

同一会话既有 Bot 解决又有转人工时，转人工优先，不计入 Bot 独立解决。

## 11. 专项分析 API

| 方法 | 路径 | 参数 | 返回重点 |
|---|---|---|---|
| GET | /api/v2/accounts/{account_id}/reports/first_response_time_distribution | since、until | 按 channel_type 的 0-1h、1-4h、4-8h、8-24h、24h+ |
| GET | /api/v2/accounts/{account_id}/reports/inbox_label_matrix | since、until、inbox_ids、label_ids | inboxes、labels、matrix |
| GET | /api/v2/accounts/{account_id}/reports/outgoing_messages_count | since、until、group_by | 按 agent、team、inbox 或 label 的发送数 |
| GET | /api/v2/accounts/{account_id}/reports/conversations | type、user_id、page | 相关会话指标列表 |

Inbox×标签 matrix 的行顺序与 inboxes 一致，列顺序与 labels 一致。不能脱离两个标题数组单独解释矩阵数字。

## 12. CSV 导出

| 路径 | 内容 |
|---|---|
| /api/v2/accounts/{account_id}/reports/agents | 成员汇总 |
| /api/v2/accounts/{account_id}/reports/teams | 团队汇总 |
| /api/v2/accounts/{account_id}/reports/inboxes | Inbox 汇总 |
| /api/v2/accounts/{account_id}/reports/labels | 标签汇总 |
| /api/v2/accounts/{account_id}/reports/conversations_summary | Account 会话汇总 |
| /api/v2/accounts/{account_id}/reports/conversation_traffic | 会话流量热力图 |

导出响应为 text/csv。文件中的时长可能已格式化为易读文本，与 JSON 的秒数不可直接按字符串比较。

## 13. 空值、延迟与一致性

- 计数没有样本时通常为 0；
- 平均时长没有样本时可能为 null、0 或缺少时间桶，按具体接口处理；
- 实时指标读取当前会话状态，趋势报表读取时间范围内的会话、消息和指标事件，两者不一定相等；
- 会话状态变化、异步汇总和时区分桶可能造成短暂延迟；
- 删除、合并或重新打开会话可能改变后续查询结果；
- 跨周期比较必须固定相同的筛选条件和营业时间开关。

## 14. 报表验收

- 用一个已知会话验证创建、首响、普通回复和解决四个时间点；
- 分别验证自然时间和营业时间秒数；
- 验证 hour、day、week、month、year 的分桶边界；
- 验证 Account、Agent、Team、Inbox、Label 维度不会跨范围；
- 验证空范围的计数和平均值展示；
- 验证 Bot 解决后又转人工时只计入转人工；
- 验证 CSV 与 JSON 在相同筛选下的样本范围一致；
- 非 Administrator 且无 report_manage 时不能访问报表。
