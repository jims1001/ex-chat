# 安全、隐私、凭证、分级、保留与合规

## 1. 安全边界

安全必须同时覆盖入口、身份、Account、对象、字段、事件、日志、导出、插件、Provider、AI 和后台任务。内部调用不能因为来自受信网络就跳过身份、Account 和能力授权。

## 2. 数据分级

| 等级 | 示例 | 默认处理 |
|---|---|---|
| public | 已公开帮助文章、公开品牌信息 | 可在公开合同范围展示 |
| internal | 普通配置摘要、非敏感运行状态 | 仅内部授权身份 |
| confidential | 客户资料、消息、会话、报表、业务设置 | 最小字段、加密和审计访问 |
| restricted | Secret、Token、MFA、支付、身份号码、高风险安全信息 | 默认 omitted、hash_only 或专用受控入口 |

每个对象、字段、Event、Webhook、日志和导出都必须继承或明确覆盖 data_classification。

## 3. 凭证规则

以下信息不得以原值进入 Data Change、普通运行日志、报表、错误、Webhook、实时事件、共享文档或普通查询：

- 密码和密码哈希；
- MFA Secret、恢复码和一次性验证码；
- Access Token、Refresh Token、API Key 和 Session Secret；
- Provider、Plugin、Agent Bot 和 Platform App Secret；
- Webhook Secret 和签名密钥；
- 证书私钥；
- 完整支付卡、银行账号和安全码。

只允许记录 secret_id、类型、状态、Scope、指纹、末尾摘要、到期时间以及创建、轮换、撤销动作。

## 4. 凭证生命周期

1. 通过专用安全入口创建或导入；
2. 保存到受控凭证存储；
3. 业务模块只获得短期引用或调用能力；
4. 查询默认只返回存在性、状态、Scope 和摘要；
5. 轮换建立新版本并保持明确切换窗口；
6. 撤销后停止新调用并处理运行中任务；
7. 删除遵守保留、Provider 撤权和恢复要求；
8. 每个生命周期动作产生安全审计，不记录秘密原值。

## 5. 数据最小化

| 场景 | 最小化规则 |
|---|---|
| API 响应 | 只返回当前身份和动作需要字段 |
| Event/Webhook | 只发送订阅合同字段，不发送完整内部对象 |
| Plugin/AI | 只传当前能力需要的上下文和内容 |
| Audit Diff | 只记录实际变化字段，敏感值遮蔽或摘要 |
| 报表 | 使用必要维度，避免暴露单客户内容 |
| 导出 | 冻结用途、范围、字段、批准和到期 |
| 运行日志 | 使用 ID、分类和摘要，不保存正文或凭证 |

## 6. 保护方式

| 方式 | 使用场景 |
|---|---|
| full | 仅低敏感且确有必要 |
| masked | 邮箱、电话、身份摘要等受限展示 |
| summary | 消息、AI 内容、批量条件等摘要 |
| hash_only | 比较前后是否变化但不允许还原 |
| tokenized | 需要关联但不展示原值 |
| encrypted | 受控保存和传输 |
| omitted | 密码、Secret、完整支付凭证等禁止内容 |

## 7. 保留和删除

每种数据明确 retention_class、起算时间、热温冷位置、到期动作和法律保留优先级。删除流程区分：业务隐藏、软删除、脱敏、归档、物理清理和清理证明。

Account 或 Contact 删除时：

1. 验证身份、范围、等待期和法律保留；
2. 冻结对象、关系、文件、AI 索引、插件数据和导出范围；
3. 各权威模块执行删除、脱敏或保留；
4. 搜索、报表、缓存和实时投影清理；
5. Provider 和插件撤权；
6. AUD 只保留政策允许的不可逆摘要；
7. ORC 对账所有步骤；
8. 未完成清理不能声明 deletion_completed。

## 8. 日志和导出访问

查看 restricted before/after、Security Audit、大范围查询、跨 Account 查询、冷归档、完整性失败或导出必须生成 Access Log。导出需要 purpose、范围、字段、approval_id、加密接收对象、下载有效期和到期清理。

## 9. 插件、Provider 和 AI

- 插件清单声明 data_classes、retention、export 和 deletion；
- Provider Payload 先验证再最小化保存；
- AI Prompt、Response、知识和 Tool 参数按 Account 策略决定 full、summary 或 omitted；
- 模型和插件不得用接收到的数据训练或保留，除非合同和 Account 明确允许；
- 外部系统故障诊断不得把 Secret 或客户正文写入普通日志；
- 新增 Scope 或数据等级必须重新授权。

## 10. 合规和数据位置

数据位置规则作用于权威数据、账本、索引、归档、备份、导出和灾备副本。跨地区传输必须有合法范围、加密、最小字段和审计。法律保留的建立、延长、解除和到期都必须记录，且不能被普通删除流程绕过。

## 11. 验收

- [ ] 所有字段、事件、日志和导出均有数据分级；
- [ ] Secret 原值在响应、日志、报表和导出中的出现数量为 0；
- [ ] 凭证创建、轮换、撤销和删除可追踪；
- [ ] Account/Contact 删除覆盖权威数据和全部副本；
- [ ] restricted 查询和导出均有 Access Log 与批准；
- [ ] 插件、AI 和 Provider 只获得最小字段；
- [ ] 保留、法律保留和数据位置规则覆盖归档与灾备。
